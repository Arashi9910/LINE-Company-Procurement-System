# LINE 群組待辦操作

## 目標與範圍
依使用者同意的操作選單、選工作修改／指派、撤回完成，全部在群組內操作，不開網頁。不啟用自動排程、不新增資料表或套件。

## 流程與驗收
- 「待辦選單」開啟入口；一般成員可查今日／我的待辦及撤回自己的已完成工作；管理員可管理今日與固定任務。
- 任務挑選卡顯示名稱而不顯示編號，每批最多六筆，使用 postback 翻頁。
- 改名：選任務 → 輸入「改名 新名稱」→ 確認卡 → 儲存。明確前綴避免誤收一般群組聊天。
- 指派：選任務 → 從已啟用授權人員／待指派中選擇 → 確認 → 儲存。
- 撤回：從本人已完成工作挑選 → 確認 → 清除完成時間並還原未完成；歷史操作保留。原完成卡亦提供入口。
- 每段操作綁定群組與操作者，10 分鐘到期，可取消；沿用操作紀錄存放對話狀態，重啟不丟失。
- 每次儲存重新檢查權限、工作快照與負責人狀態。舊按鈕、其他人按鈕不能變更工作。重送事件與重複確認不重複寫入或回覆。

## 結構與實作順序
1. `src/line/todo-management.js`：選單、工作／成員挑選、確認卡；沿用深色配色。
2. `src/services/todo-management.js`：交易內對話狀態、解析、到期／快照檢查。
3. `src/services/daily-todos.js`：整合既有交易與權限，不另開巢狀寫入佇列。
4. `src/sheets/repository.js`：讀取授權名單；不改資料表結構。
5. 測試、LINE 官方卡片驗證，再套用獨立發布分支部署。

## 慣例與驗證
沿用 ESM、兩空格、具名函式與既有 ValidationError／AuthorizationError。
`npm test`、`npm run lint`、`npm run build`。測試涵蓋完整改名／指派／撤回、多人隔離、重啟續用、逾時、取消、停權、快照衝突、重送及清單超量分頁；測試不可真的推播群組。

## 邊界
只修改授權功能範圍；保留固定範本當日凍結規則、原指令、完成防洗頻與補貨流程。新增依賴／資料結構變更另行確認。禁止提交憑證。
